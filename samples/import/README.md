# Примеры файлов для импорта

Три выгрузки в формате 1С для раздела **Импорт** в кабинете сотрудника. Адреса почты в примерах уникальны (`@demo.hostel`).

| Файл | Содержимое |
|------|------------|
| `import-01-muzhskie.xlsx` | 6 студентов, мужской пол (для мужских комнат) |
| `import-02-zhenskie.xlsx` | 6 студентов, женский пол (для женских комнат) |
| `import-03-lgoty-i-dopolnitelno.xlsx` | 5 человек: иногородние, многодетная семья, сирота |

Колонки совпадают с шаблоном на сайте. После импорта заявки в статусе «Подана» — допустите и проверьте документы, затем можно селить на **Жилой фонд**.

Пересобрать файлы: `node scripts/generate-import-samples.mjs` (нужен `xlsx` в `Chikanenko-Back`).
