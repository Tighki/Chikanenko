# Заселение в общежитие

Фронт дипломной системы. API живёт отдельно: https://github.com/Tighki/Chikanenko-Back

## Порты

На роутере, TCP, на IP машины, где запущен процесс:

| Сервис | Порт | Комментарий |
| --- | --- | --- |
| Этот фронт | 5173 | front |
| API | 4000 | api |

PostgreSQL (`5432`) не пробрасывать.

## Env

Адрес в `VITE_API_URL` браузер вызывает сам. Это должен быть адрес, доступный с того компьютера, где открыт сайт. Для входа из интернета — внешний IP или домен и порт `4000`. Для входа только из локальной сети — `192.168.1.x:4000`.

```bash
cp .env.example .env
```

```env
VITE_API_URL=http://203.0.113.10:4000
VITE_HOST=0.0.0.0
VITE_PORT=5173
```

Тот же адрес страницы (`http://203.0.113.10:5173`) записывается в `CORS_ORIGIN` на бэке.

`VITE_API_URL` вшивается при сборке. После смены адреса снова выполните `npm run build`. Пустое значение оставляет запросы на `/api`: так удобно на одной машине, Vite пересылает их на `127.0.0.1:4000`.

## Запуск

```bash
npm install
npm run build
npm run preview
```

Сайт: `http://127.0.0.1:5173`.

`npm run dev` поднимает режим разработки с тем же портом и читает `.env` без отдельной сборки.
