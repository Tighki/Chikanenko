# Информационная система автоматического заселения в общежитие

Веб-приложение для диплома: абитуриент подаёт заявку, сотрудник общежития проверяет документы и запускает автозаселение, администратор ведёт льготы, кампанию и журнал.

## Стек

- Клиент: React, TypeScript, Vite
- Сервер: Node.js, Express, TypeScript, Prisma
- База: PostgreSQL

## Запуск через Docker

Нужны Node.js 20+ и Docker.

```bash
docker compose up -d
copy .env.example server\.env
npm install
npm install --prefix server
npm install --prefix client
npm run db:setup --prefix server
npm run dev
```

Клиент: http://localhost:5173  
API: http://localhost:4000

Направление в PDF собирается шрифтом DejaVu, если файлы лежат в `server/assets/fonts`. Если их нет, на Windows используется Arial.

## Запуск без Docker

Если Docker не установлен, встроенный PostgreSQL поднимается отдельной командой. Окно нужно оставить открытым.

```bash
npm install
npm install --prefix server
npm install --prefix client
copy .env.example server\.env
npm run db:local
```

Во втором окне:

```bash
npm run db:setup --prefix server
npm run dev
```

`db:setup` применяет миграции и заполняет демонстрационные данные. Повторный запуск сида очищает базу и создаёт данные заново: `npm run db:seed --prefix server`.

## Сценарий демонстрации

1. Войти как `sokolov@hostel.local` и показать анкету, заявку и документы.
2. Войти как `staff@hostel.local`. На сводке видны свободные койки и две заявки, которые ещё ждут проверки: Егоров и Белова.
3. Открыть заявку Беловой, принять документы и нажать «Допустить».
4. Открыть «Автозаселение», нажать «Рассчитать» и показать порядок: льгота, балл, дата подачи. Инвалидность получает комнату доступной среды. Кому не хватило места, тот попадает в очередь.
5. Нажать «Подтвердить распределение». Уже заселённые при повторном запуске не переназначаются.
6. Открыть «Отчёт» и скачать PDF-направление.
7. Войти абитуриентом из очереди, например `novikov@hostel.local`, и показать статус. Затем сотрудником вручную назначить ему свободную койку на странице «Назначения».
8. Администратором показать порядок льгот, сроки кампании и журнал.

## Алгоритм

К распределению берутся заявки в статусах «Допуск» и «Очередь» без назначенной койки и с проверенными обязательными документами.

Сортировка:

1. Ранг льготы. По умолчанию: сироты, инвалидность, многодетные и малоимущие, иногородние, без льготы.
2. Вступительный балл по убыванию.
3. Более ранняя дата подачи.

Подбор койки: тот же пол, комната открыта, койка свободна. Для инвалидности сначала комнаты доступной среды. Для остальных доступная среда используется только когда обычных мест не осталось. Опция «группировать по факультету» предпочитает комнату, где этот факультет уже есть, затем пустую комнату. Если места нет, заявка остаётся в очереди.

## Импорт

Файл Excel или CSV с колонками: ФИО, Пол, Дата рождения, Город, Регион, Факультет, Направление, Балл, Категория, Email, Телефон. Категория: сирота, инвалидность, социальная, иногородний, нет. Новым абитуриентам выдаётся временный пароль, его нужно сменить при входе.
